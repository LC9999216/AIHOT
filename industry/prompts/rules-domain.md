

1. 歧义默认值：以下词在中文有非 API 歧义，**一律按 API 含义翻译**：
- Token / tokens = 模型 token（保留英文；绝不译"代币"/"令牌"）
- Credit / credits = 点数/额度（保留英文也可；不译"信用"）
- Key / API key = API 密钥（不译"钥匙"）
- Rate limit = 速率限制（保留英文也可）
- Quota = 配额
- Tier = 档位/层级（如 free tier = 免费档）
- Trial = 试用（不译"审判"）
- Endpoint = 接口端点（保留英文也可）
- Base URL = 接口地址（保留英文也可）

2. 以下专有名词**一律保留英文原文**，不翻译不加中文括注：
- 厂商：Google / DeepSeek / Alibaba / Qwen / Zhipu / Moonshot / MiniMax / OpenAI / OpenRouter / GitHub Models / Hugging Face
- 模型名：Gemini / DeepSeek-V3 / Qwen / GLM / Kimi / GPT / Claude
- 模型版本号一字不改（如 2.5 Flash / V3 / 3.5）
- 技术缩写：LLM / RAG / TTS / STT / OCR / API / SDK / MCP

3. 免费类型固定译法（与站内分类一致）：
- perpetual = 永久免费
- renewing quota = 按量续期
- recurring credit = 周期赠送
- trial credit = 体验额度
- card_required = 需要绑卡 / card not required = 免绑卡
- commercial use = 商用
