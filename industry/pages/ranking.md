# 热度算法

本站的免费 API 热度榜按固定公式计算，不猜、不黑箱。当前版本：**fth-heat-v1**。

| 项 | 值 |
|---|---|
| 版本 | fth-heat-v1 |
| 生效日期 | 2026-09-30 |

## 公式

```
热度 = 免费类型基础分
     + OpenAI 兼容 15 分
     + 商用允许 10 分
     + 免绑卡 10 分
     + min(免费模型数 × 2, 20)
```

## 免费类型基础分

| 免费类型 | 基础分 | 说明 |
|---|---|---|
| 永久免费 | 100 | 长期有效的免费额度，不过期 |
| 按量续期 | 80 | 每天/每月自动重置的免费额度 |
| 周期赠送 | 60 | 定期发放的 credits 或代金券 |
| 体验额度 | 40 | 新用户一次性试用额度 |

## 加分项

- **OpenAI 兼容（+15）**：接口兼容 OpenAI 格式，改个 base_url 就能迁移。
- **商用允许（+10）**：免费额度可用于商业用途。
- **免绑卡（+10）**：不需要绑定信用卡就能用。
- **模型数奖励（+2/模型，上限 20）**：免费的模型越多，能做的事越多。

## 说明

- 所有输入数据来自 FTH 免费 API 注册表，每条都经过官方文档验证。
- 分数只反映"值得薅"的程度，不构成购买或使用建议；各厂商条款可能随时变更，使用前请以官方文档为准。
- 公式升级时会更新这里的版本号，历史榜单保留当时的版本标记。
